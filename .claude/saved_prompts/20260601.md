# Task: Compute a KS-like Shape-Compatibility Test Statistic for pPb vs Pbp

## Goal

Compute a **KS-like test statistic** for the pPb and Pbp projected observables
by comparing their **normalized cumulative distributions** bin-by-bin.

This is intended as a **shape-only diagnostic**. It does **not** incorporate
jackknife uncertainties or bin-to-bin covariance, and it should therefore be
treated as a secondary cross-check rather than the primary statistical
compatibility test.

Do **not** interpret the result. Just return the numerical test statistic
values and the intermediate normalized cumulative distributions.

---

## Scope

Apply this to the final projected 1D observables used in the analysis, e.g.

- `DeltaEta_Result`
- `DeltaPhi_Result`

for the pPb and Pbp datasets.

If both observables are available, compute the KS-like statistic for each.

---

## Inputs

For each observable, obtain:

- the pPb 1D histogram bin contents: `h_pPb[i]`
- the Pbp 1D histogram bin contents: `h_Pbp[i]`

Use the **final plotted 1D observable** after all standard processing:

- combination logic within a dataset already applied as usual,
- subtraction already applied if this is a subtracted observable,
- final presentation normalization already applied if that is what is plotted.

Use the same binning for pPb and Pbp.

### Bin handling
- Use only the regular histogram bins.
- Exclude underflow and overflow bins.
- Preserve the natural bin ordering along the axis.

---

## Definition of the KS-like statistic

For each histogram, first normalize the bin contents to unit area:

```text
p_i = h_pPb[i] / sum_j h_pPb[j]
q_i = h_Pbp[i] / sum_j h_Pbp[j]
```

Then form the cumulative distributions:

```text
P_k = sum_{i <= k} p_i
Q_k = sum_{i <= k} q_i
```

The KS-like statistic is:

```text
D_KS = max_k |P_k - Q_k|
```

This is the maximum absolute difference between the normalized cumulative
distributions.

---

## Important caveat about signed histograms

The standard KS construction assumes nonnegative distributions. Your
subtracted correlation observables may contain negative bin contents.

### Required handling
Before computing the KS-like statistic, check whether **all** included bins
in **both** histograms are nonnegative.

#### Case 1: all bins are nonnegative
Proceed with the standard normalization above.

#### Case 2: one or more bins are negative
Do **not** attempt to interpret the histogram as a probability distribution.
Instead, compute and return one of the following two diagnostics:

### Preferred fallback: shifted-shape KS-like statistic
Define a common shift:

```text
c = - min( min_i h_pPb[i], min_i h_Pbp[i] ) + epsilon
```

where `epsilon` is a tiny positive number, e.g. `1e-12 * max(abs(h))` or
simply `1e-12` in histogram units if values are O(1).

Then define shifted histograms:

```text
h'_pPb[i] = h_pPb[i] + c
h'_Pbp[i] = h_Pbp[i] + c
```

These are guaranteed positive. Then compute:

```text
p_i = h'_pPb[i] / sum_j h'_pPb[j]
q_i = h'_Pbp[i] / sum_j h'_Pbp[j]
P_k = sum_{i <= k} p_i
Q_k = sum_{i <= k} q_i
D_KS_shifted = max_k |P_k - Q_k|
```

Return this value and clearly label it as the **shifted KS-like statistic**.

### Also return the raw L-infinity cumulative difference
Even in the negative-bin case, also compute the cumulative sums of the
**unnormalized** histograms:

```text
C_pPb[k] = sum_{i <= k} h_pPb[i]
C_Pbp[k] = sum_{i <= k} h_Pbp[i]
```

and return

```text
D_cum_raw = max_k |C_pPb[k] - C_Pbp[k]|
```

This is not a KS statistic, but it is a useful cumulative-shape diagnostic.

---

## Primary calculation procedure

For each observable:

### Step 1: Read the histograms
Obtain the pPb and Pbp 1D histograms with matching binning.

### Step 2: Check for validity
- Confirm the number of bins is the same.
- Exclude underflow/overflow.
- Check whether any regular-bin contents are negative.

### Step 3: If all bins are nonnegative
Compute:

```text
sum_pPb = sum_i h_pPb[i]
sum_Pbp = sum_i h_Pbp[i]
```

If either sum is zero, flag the observable as invalid for KS-like testing.

Otherwise compute normalized bin contents:

```text
p_i = h_pPb[i] / sum_pPb
q_i = h_Pbp[i] / sum_Pbp
```

Then cumulative distributions:

```text
P_k = sum_{i <= k} p_i
Q_k = sum_{i <= k} q_i
```

Then the KS-like statistic:

```text
D_KS = max_k |P_k - Q_k|
```

### Step 4: If negative bins are present
Compute:

1. the shifted KS-like statistic `D_KS_shifted`
2. the raw cumulative-difference diagnostic `D_cum_raw`

as described above.

Do **not** compute a formal KS p-value in this case unless explicitly asked.

---

## Optional formal KS p-value

If and only if **all bins are nonnegative** and the user wants a formal
two-sample KS-style p-value, approximate the effective sample sizes using
the total integrals:

```text
n_eff_pPb = sum_i h_pPb[i]
n_eff_Pbp = sum_i h_Pbp[i]
```

and use the standard two-sample KS asymptotic formula or library
implementation.

### Important warning
This p-value is only heuristic for histogrammed weighted observables and is
**not** the primary quantity of interest. The main requested output is the
test statistic `D_KS`.

If a p-value is computed, clearly label it as an **approximate KS p-value**.

---

## Deliverables

For each observable, return:

### If all bins are nonnegative

## Pseudocode

### Standard nonnegative case

```python
hp = [ ... ]   # pPb bin contents
hq = [ ... ]   # Pbp bin contents

sum_hp = sum(hp)
sum_hq = sum(hq)

p = [x / sum_hp for x in hp]
q = [x / sum_hq for x in hq]

P = []
Q = []
cp = 0.0
cq = 0.0
for pi, qi in zip(p, q):
    cp += pi
    cq += qi
    P.append(cp)
    Q.append(cq)

D_KS = max(abs(a - b) for a, b in zip(P, Q))
```

### Shifted fallback case

```python
hp = [ ... ]
hq = [ ... ]

c = -min(min(hp), min(hq)) + 1e-12

hp_shift = [x + c for x in hp]
hq_shift = [x + c for x in hq]

sum_hp = sum(hp_shift)
sum_hq = sum(hq_shift)

p = [x / sum_hp for x in hp_shift]
q = [x / sum_hq for x in hq_shift]

P = []
Q = []
cp = 0.0
cq = 0.0
for pi, qi in zip(p, q):
    cp += pi
    cq += qi
    P.append(cp)
    Q.append(cq)

D_KS_shifted = max(abs(a - b) for a, b in zip(P, Q))

C_pPb = []
C_Pbp = []
cp_raw = 0.0
cq_raw = 0.0
for x, y in zip(hp, hq):
    cp_raw += x
    cq_raw += y
    C_pPb.append(cp_raw)
    C_Pbp.append(cq_raw)

D_cum_raw = max(abs(a - b) for a, b in zip(C_pPb, C_Pbp))
```
