# Test of residual track correction eta-phi 2D simultaneous
Take a look at the residual track correction implemented in MainAnalysis/20251211_ResidualCorrection and the description of the correction calculation in the Track Reconstruction section of the analysis note. Currently we correct track pt, eta, phi by projecting each dimension to 1D and then taking the ratio at the 1D level of gen- and reco-level MC.

This however projects out correlations between eta and phi dimensions. Indeed we see hot and cold spots in data and  even MC reco eta-phi map after track corrections are applied, in pp, pPb and Pbp.

## new correction
We will attempt to fix this by making a new residual correction script at MainAnalysis/20260518_ResidualCorrection2D. Make runner.sh scripts and corrections scripts in the style of those at 20251211_ResidualCorrection (which we will keep around as a fallback) at workflow_2D where we not correct eta-phi distribution as a simulatneous correction, i.e. divide the 2D eta-phi projection of the 3D pt eta phi dist for a 2D eta-phi correction. Continue to correct for track pT as a 1D correction. Continue to use three iterations. You will need to implement a new class in the header file at common code. Place this new function in the same file as the current residual correction header file. Correction files should have two histograms: a TH1 correction for pT and TH2 correction for eta-phi. Try to make the new scripts as consistent as possible with the triple-1D correction. Report back any clear bugs.

## plotting
To visualize closure of the correction, produce a new 3x2 plot, each row is one of the three iterations, the left plot is the pT correction for that iteration, and the right plot is a 2D eta-phi map of the eta-phi 2D correction for that iteration. Make the plot using similar style to the correction plots in 20251211. Additionally, make the same closure plots as in 20251211 called isPP_*. The same plotting script can probably be used for these.

## testing with pp
Setup the correction to run on the pp, pPb and Pbp systems. Apply the new correction scheme on pp for the 0-10 10-20 20-40 40-500 ZpT bins as a test. Make the plots outlined above. We should see closure, verify that the 1D and 2D corrections converge by checking the thrid iteration corrections are near-1 for pt and eta-phi. If they are off then iterate assuming this is a bug. Make sure to use a naming scheme with todays date and to not override any of the official weight tables or frozen .root file used in the analysis note.
